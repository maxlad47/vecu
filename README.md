# Vécu

Apprendre une langue avec des phrases de la vraie vie, en 2 minutes comme en 30, en silence comme en voiture, même hors ligne.

*Nom de code provisoire. Projet en phase 0 (prototype).*

- Constitution du projet : [`CLAUDE.md`](CLAUDE.md)
- Pilotage, décisions et feuille de route : [`docs/pilotage.md`](docs/pilotage.md)
- Journal des décisions : [`docs/journal.md`](docs/journal.md)
- L'équipe : [`.claude/agents/`](.claude/agents/)

## L'équipe

| Agent | Rôle |
|---|---|
| CEO (session principale) | Vision, priorités, arbitrages, validation |
| `pedagogue` | Situations, progression, phrases-moules, règles de session |
| `linguiste-russe` | Traduction, accent tonique, genre, registre, fichiers de contenu |
| `designer-ux` | Parcours, écrans, système visuel, accessibilité |
| `dev-pwa` | Code de l'app, hors ligne, audio, moteur de session |
| `testeur-qa` | Vérification avant livraison, rapports |
| `utilisateur-temoin` | Avis franc d'un vrai débutant pressé |
