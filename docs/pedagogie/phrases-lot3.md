# Phrases du lot 3 (français uniquement)

Auteur : pedagogue. Statut : proposition, à valider par le CEO, puis à traduire par `linguiste-russe`.
Langue cible : russe. Niveau : A1. Mission 004 (branche `mission-004-lot3`). 5 situations, 50 éléments, dont 10 phrases-moules. Aucune phrase en commun avec les 96 éléments de `phrases-phase0.md` et `phrases-lot2.md`.
Conventions (registre, genre, astuce, moule, ordre dans la situation) : identiques à `phrases-phase0.md`. Elles ne sont pas répétées ici.
Genre : les 50 éléments ont été écrits au présent ou en tournures impersonnelles, pour qu'aucune ne demande `variantes.m` / `variantes.f`. Si Nadia en trouve une qui change quand même, elle la signale.

## Ordre d'introduction

Même règle par vagues : vague 1 = éléments 1 à 3 de chaque situation, vague 2 = 4 à 6, vague 3 = 7 à 10. Rang des situations dans `index.json` (à confirmer par Nadia en complétant l'index) : hotel (11), telephone (12), amis (13), banque (14), meteo (15). Clé de tri inchangée : `(vague, rang de la situation, rang de la phrase)`. Les éléments déjà vus ne bougent pas.

## 11. À l'hôtel (`hotel`) : registre vous

Objectif : « Je sais m'installer à l'hôtel et régler un petit problème de chambre. »

| id | Phrase | Registre | Genre | Intention d'astuce |
|---|---|---|---|---|
| ru-hotel-001 | J'ai une réservation. | vous | non | |
| ru-hotel-002 | **MOULE** « Je reste ___. » | neutre | non | La durée se dit sans préposition pour « une nuit », mais avec un petit mot pour « jusqu'à ». À apprendre en bloc. |
| ru-hotel-003 | Ma clé ne marche pas. | neutre | non | |
| ru-hotel-004 | Quel est le mot de passe du wifi ? | neutre | non | |
| ru-hotel-005 | À quelle heure est le petit-déjeuner ? | neutre | non | |
| ru-hotel-006 | **MOULE** « Il n'y a pas ___ dans la chambre. » | neutre | non | Après « il n'y a pas de », le nom change de terminaison. Une seule règle pour tous les noms. |
| ru-hotel-007 | Je peux laisser mes bagages ici ? | vous | non | |
| ru-hotel-008 | Vous pouvez appeler un taxi ? | vous | non | |
| ru-hotel-009 | Il y a une chambre plus calme ? | vous | non | |
| ru-hotel-010 | Je pars demain matin. | neutre | non | |

Remplacements :
- **ru-hotel-002** « Je reste ___. » : une nuit / deux nuits / trois nuits / une semaine / jusqu'à samedi
- **ru-hotel-006** « Il n'y a pas ___ dans la chambre. » : de serviettes / d'eau chaude / de papier toilette / de savon / de chauffage (corrigé le 12/11 : élision)

Choix : « Je voudrais une chambre » est écartée (« je voudrais » change selon le genre, et on réserve avant d'arriver). 003 et 006 couvrent les deux pannes les plus fréquentes. 010 est au présent : neutre.

## 12. Au téléphone (`telephone`) : registre vous

Objectif : « Je sais me faire comprendre au téléphone : faire épeler, faire répéter, rappeler. »
Règle : phrases pour comprendre et se faire comprendre. Aucun script de conversation longue.

| id | Phrase | Registre | Genre | Intention d'astuce |
|---|---|---|---|---|
| ru-telephone-001 | Allô ? | neutre | non | |
| ru-telephone-002 | Je vous entends mal. | vous | non | |
| ru-telephone-003 | Vous pouvez épeler, s'il vous plaît ? | vous | non | |
| ru-telephone-004 | **MOULE** « Je peux parler ___ ? » | vous | non | Le nom de la personne change de terminaison. Apprends-le en bloc. |
| ru-telephone-005 | **MOULE** « Rappelez-moi ___, s'il vous plaît. » | vous | non | |
| ru-telephone-006 | Vous pouvez m'envoyer un SMS ? | vous | non | |
| ru-telephone-007 | C'est qui ? (remplace « Vous pouvez parler plus fort ? », 12/11) | neutre | non | |
| ru-telephone-008 | Je vous rappelle plus tard. | vous | non | |
| ru-telephone-009 | Ce n'est pas le bon numéro. | neutre | non | |
| ru-telephone-010 | Mon numéro, c'est le… (remplace « Notez mon numéro », 12/11) | neutre | non | |

Remplacements :
- **ru-telephone-004** « Je peux parler ___ ? » : à Ivan / à Irina Petrovna / au directeur / à la réception / au médecin (corrigé le 12/11 : contractions, parenthèse retirée)
- **ru-telephone-005** « Rappelez-moi ___, s'il vous plaît. » : demain / ce soir / lundi / dans une heure / plus tard

Choix : « Vous pouvez répéter » et « Plus lentement » existent déjà dans `rencontrer` : on ne les redouble pas. 006 (le SMS) est le recours réel quand on ne comprend pas le nom ou le nombre. « Je me suis trompé de numéro » est écartée (passé, le genre change) au profit de 009.

## 13. Chez des amis (`amis`) : registre tu

Objectif : « Je sais arriver chez des amis, me tenir à table et dire merci en partant. »
L'ordre suit le déroulé réel d'une soirée : arriver, s'installer, manger, partir.

| id | Phrase | Registre | Genre | Intention d'astuce |
|---|---|---|---|---|
| ru-amis-001 | Merci pour l'invitation. | neutre | non | |
| ru-amis-002 | Tiens, c'est pour toi. (un cadeau, des fleurs) | tu | non | |
| ru-amis-003 | Je peux enlever mes chaussures ? | neutre | non | |
| ru-amis-004 | **MOULE** « Je peux ___ ? » (demander la permission) | neutre | non | Un seul petit mot suivi du verbe à l'infinitif suffit pour demander la permission. |
| ru-amis-005 | **MOULE** « Passe-moi ___, s'il te plaît. » | tu | non | |
| ru-amis-006 | À la tienne ! (au moment de trinquer) | tu | non | |
| ru-amis-007 | Je n'ai plus faim, merci. | neutre | non | |
| ru-amis-008 | Tu veux un coup de main ? (remplace « Tu habites ici depuis longtemps ? », 12/11) | tu | non | |
| ru-amis-009 | Il est tard, je dois y aller. | neutre | non | |
| ru-amis-010 | Merci pour la soirée, c'était super ! | neutre | non | |

Remplacements :
- **ru-amis-004** « Je peux ___ ? » : prendre un verre d'eau / ouvrir la fenêtre / charger mon téléphone / aider / m'asseoir
- **ru-amis-005** « Passe-moi ___, s'il te plaît. » : le sel / le pain / l'eau / la salade / ça

Choix : « Merci pour l'invitation » plutôt que « Merci de m'avoir invité » (invité / invitée). 007 existe parce qu'on insiste pour resservir : savoir refuser poliment sert dès le premier repas. 009 se dit avec une tournure impersonnelle en russe (neutre). Les remplacements de 004 évitent « payer par carte » (déjà dans `cafe`).

## 14. Banque et argent (`banque`) : registre vous

Objectif : « Je sais retirer de l'argent, payer et me débrouiller quand la carte ne passe pas. »
Règle : phrases du quotidien uniquement, aucun conseil financier. L'app n'explique ni frais, ni taux, ni produit bancaire.

| id | Phrase | Registre | Genre | Intention d'astuce |
|---|---|---|---|---|
| ru-banque-001 | Il y a un distributeur près d'ici ? | neutre | non | |
| ru-banque-002 | Ma carte ne passe pas. | neutre | non | |
| ru-banque-003 | Je veux retirer de l'argent. | neutre | non | |
| ru-banque-004 | Je veux bloquer ma carte. | neutre | non | |
| ru-banque-005 | Le distributeur a avalé ma carte. | neutre | non | |
| ru-banque-006 | **MOULE** « Vous avez la monnaie de ___ ? » | vous | non | |
| ru-banque-007 | Je peux payer en espèces ? | vous | non | |
| ru-banque-008 | **MOULE** « Je veux changer ___ en roubles. » | neutre | non | Les nombres changent de forme selon le chiffre. Apprends chaque phrase en bloc. |
| ru-banque-009 | Il y a une commission ? | vous | non | |
| ru-banque-010 | Vous pouvez me donner un reçu ? | vous | non | |

Remplacements :
- **ru-banque-006** « Vous avez la monnaie de ___ ? » : cent roubles / cinq cents roubles / mille roubles / cinq mille roubles / ce billet
- **ru-banque-008** « Je veux changer ___ en roubles. » : cent euros / deux cents euros / cinq cents euros / cinquante dollars / mille euros

Choix : « Je veux » (présent) plutôt que « Je voudrais » (genre). 004 est placée avant 005 : bloquer sa carte est plus urgent qu'un distributeur capricieux. Écartées : « J'ai oublié mon code » (passé, genre), tout ce qui touche à l'ouverture de compte, au crédit ou à l'épargne.

## 15. Le temps qu'il fait (`meteo`) : registre neutre

Objectif : « Je sais demander et dire le temps qu'il fait, pour m'habiller et pour faire la conversation. »

| id | Phrase | Registre | Genre | Intention d'astuce |
|---|---|---|---|---|
| ru-meteo-001 | Quel temps il fait ? | neutre | non | |
| ru-meteo-002 | **MOULE** « Il fait ___ aujourd'hui. » | neutre | non | En russe, le temps se dit avec un petit mot invariable : pas de verbe « faire ». |
| ru-meteo-003 | Il pleut. | neutre | non | |
| ru-meteo-004 | Il neige. | neutre | non | |
| ru-meteo-005 | Quel temps il fera demain ? | neutre | non | |
| ru-meteo-006 | **MOULE** « Il va ___ ? » (remplace « Demain, il y aura ___. », 12/11) | neutre | non | |
| ru-meteo-007 | J'ai froid. | neutre | non | « J'ai froid » se dit sans sujet en russe : une seule forme pour tous. |
| ru-meteo-008 | Il fait combien de degrés ? | neutre | non | |
| ru-meteo-009 | Il faut un parapluie ? | neutre | non | |
| ru-meteo-010 | Il fait froid, hein ? (remplace « On a de la chance avec la météo ! », 12/11) | neutre | non | |

Remplacements :
- **ru-meteo-002** « Il fait ___ aujourd'hui. » : beau / chaud / froid / frais / mauvais
- **ru-meteo-006** « Il va ___ ? » : pleuvoir / neiger / faire froid / faire chaud / y avoir de l'orage

Choix : « Il fait beau / chaud / froid » vivent dans le moule 002, pas en phrases seules, pour ne pas doublonner. 007 est la seule phrase de la situation qui parle de la personne ; elle est impersonnelle donc neutre.

## Phrases écartées au test du vécu (pour mémoire)

- « Je voudrais une chambre pour deux » : on réserve avant d'arriver, et « je voudrais » change selon le genre.
- « Où est le distributeur ? » : doublon de fait avec le moule `metro-001` ; remplacée par « Il y a un distributeur près d'ici ? » (calque de `pharmacie-001`).
- « Je me suis trompé de numéro », « J'ai oublié mon code » : passé, le genre change la forme russe.
- « Quel est votre taux de change ? », « Je voudrais ouvrir un compte » : conseil ou démarche financière, hors périmètre.
- « Il fait beau », « Il fait froid » en phrases seules : couvertes par le moule `meteo-002`.
- « Ne quittez pas », « Un instant » : on les entend plus qu'on ne les dit ; la compréhension orale viendra avec l'audio.
